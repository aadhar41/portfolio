# Contributing to Full Stack Portfolio

First off, thank you for considering contributing to this project! It's people like you that make the open-source community such an amazing place to learn, inspire, and create.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create a new issue using the **Bug Report** template. Include as much detail as possible, such as steps to reproduce and screenshots.

### Suggesting Enhancements
We love hearing new ideas! Use the **Feature Request** template to suggest new features or improvements.

### Pull Requests
1. Fork the repository and create your branch from `master`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes.
4. Issue a pull request!

## Style Guide

### Git Commit Messages
- Use the present tense ("Add feature" not "Added feature")
- Use the imperative mood ("Move cursor to..." not "Moves cursor to...")
- Limit the first line to 72 characters or less

### Code Style
- Stick to the existing formatting (Laravel/PHP standards for the backend, Prettier/ESLint for the frontend).
- Comment your code where necessary for complex logic.
